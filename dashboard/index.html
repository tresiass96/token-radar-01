Board Live tokens Methodology

How to read this page. The board ranks protocols that record no token, by implied value — what a launch would be worth if the market priced them like the tokened protocols in their own category. Tokened protocols are never ranked here; they are used only as comparables, and shown separately under Live tokens.

All figures are computed from the sealed snapshot; runs are byte-identical. Read the full methodology.
